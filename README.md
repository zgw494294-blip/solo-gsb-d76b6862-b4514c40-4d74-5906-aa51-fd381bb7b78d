# Python 逐行执行观察器

在网页上逐行观察本机可信 Python 代码的实际执行：Flask + 原生 HTML/CSS/JavaScript，
每次运行在独立子进程中进行（`bdb` 跟踪），先停在首条待执行行，可单步、继续或终止。

## 启动

```bash
docker compose up --build
```

访问地址：<http://localhost:8000>（端口 **8000**）

本地直接运行（可选）：`pip install -r requirements.txt && python app.py`，同样访问 8000 端口。

## 功能

- 编辑器最多接受 **80 行**代码，超出会被拒绝；页面内置赋值、函数调用、循环、异常四个示例。
- **运行**：在独立子进程中启动，自动停在第一条待执行行；运行期间源码只读。
- **单步**：停在下一条实际将执行的源码行（会进入函数调用、跟随循环逐次迭代）。
- **继续**：一直执行到结束或异常；**终止**：强制结束并回收子进程。
- 实时显示：下一条待执行行（高亮 + `→`）、当前局部变量的文本值、标准输出、异常堆栈。
- 暂停中或死循环（继续后）都可以随时查询状态或终止。

## 并发与一致性规则

- 全站同一时刻只允许一个未结束的运行；结束（子进程已退出**且已回收**）后可修改代码再次运行。
- 控制请求（单步/继续/终止）携带 `run_id`；单步/继续还携带停顿序号 `pause_seq`。
- 同一次停顿最多接受一次控制请求：重复或过期请求返回 409 且不会推进执行。
- 前端只采纳与当前 `run_id` 匹配的状态响应，旧运行的迟到响应会被丢弃。

### 启动期终止竞态（已修复）

旧实现在 `POST /api/run` 中先登记运行、再在锁外创建子进程。若终止请求恰好在
“运行已登记、子进程尚未挂接”的窗口到达：终止拿到的是 `proc = None`，会直接返回
成功；原启动随后照常创建子进程。紧接着重跑会成功并再建一个子进程，而旧 `run_id`
已不是当前运行、无法终止旧子进程——最终遗留两个存活/未回收进程。

修复后的协调保证：

- **终止成功即无残留**：`/api/terminate` 返回 `200` 时，该运行的子进程已经退出
  并被回收（`wait()` 完成）；终止在子进程尚未挂接时会登记终止意图并等待启动完成，
  由启动方直接杀掉并回收刚创建的子进程，未完成的启动不会再遗留进程。
- **旧进程回收前不接纳下一次运行**：`/api/run` 仅当上一运行 `reaped` 后才允许，
  否则返回 409；因此“终止后立即重跑”最多只有一个存活子进程。
- **迟到事件不会复活状态**：子进程在终止后仍可能刷出的 `pause`/`stdout`/`end`
  事件一律丢弃，状态保持 `terminated`，不会被改回 `paused`/`finished`。
- **旧 `run_id` 失效**：重跑后旧标识的控制请求返回 409，无法触达新进程。

接口与取值不变：`POST /api/run` 仍接收 `code`、返回 `{run_id}`；`POST /api/terminate`
仍接收 `run_id`、返回 `{ok, status}`；单运行冲突与过期控制请求仍为 409；步进/继续的
`run_id`、`pause_seq` 与“同一次停顿只接受一次”的去重规则不变；`GET /api/state` 可继续查询。

## 竞态核对

`race_check.py` 使用可控线程交错（门控 `Popen` / 假子进程）核对，无需联网或额外依赖
（只需能导入 Flask）：

```bash
pip install -r requirements.txt
python race_check.py
```

覆盖：启动期终止 + 立即重跑（断言只剩一个存活子进程且旧 `run_id` 返回 409）、
活动运行时重跑 409、终止后迟到事件不改状态、正常暂停的步进/继续去重、
死循环继续后终止回收，以及 40 轮启动期随机时刻终止的模糊测试。


## 限制

- 不支持交互式输入（`input()` 会得到 EOF 异常）与第三方包（仅标准库）。
- 标准输出保留最近约 100K 字符，超出部分截断。

## 接口

| 方法 | 路径 | 请求体 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/run` | `{code}` | 启动运行，返回 `{run_id}`；已有活动运行返回 409 |
| POST | `/api/step` | `{run_id, pause_seq}` | 单步；重复/过期返回 409 |
| POST | `/api/continue` | `{run_id, pause_seq}` | 继续至结束；重复/过期返回 409 |
| POST | `/api/terminate` | `{run_id}` | 终止并回收子进程 |
| GET | `/api/state` | — | 当前运行完整状态（含 `run_id`、行号、局部变量、输出、异常） |
