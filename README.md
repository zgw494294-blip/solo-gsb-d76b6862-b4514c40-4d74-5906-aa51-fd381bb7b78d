# Python 逐行执行观察器

在网页上逐行观察本机可信 Python 代码的实际执行：Flask + 原生 HTML/CSS/JavaScript，
每次运行在独立子进程中进行（`bdb` 跟踪），先停在首条待执行行，可单步、继续或终止。

## 启动

```bash
docker compose up --build
```

访问地址：<http://localhost:8000>（端口 **8000**）

本地直接运行（可选）：`pip install -r requirements.txt && python app.py`，同样访问 8000 端口。

## 功能

- 编辑器最多接受 **80 行**代码，超出会被拒绝；页面内置赋值、函数调用、循环、异常四个示例。
- **运行**：在独立子进程中启动，自动停在第一条待执行行；运行期间源码只读。
- **单步**：停在下一条实际将执行的源码行（会进入函数调用、跟随循环逐次迭代）。
- **继续**：一直执行到结束或异常；**终止**：强制结束并回收子进程。
- 实时显示：下一条待执行行（高亮 + `→`）、当前局部变量的文本值、标准输出、异常堆栈。
- 暂停中或死循环（继续后）都可以随时查询状态或终止。

## 并发与一致性规则

- 全站同一时刻只允许一个未结束的运行；结束后可修改代码再次运行。
- 控制请求（单步/继续/终止）携带 `run_id`；单步/继续还携带停顿序号 `pause_seq`。
- 同一次停顿最多接受一次控制请求：重复或过期请求返回 409 且不会推进执行。
- 前端只采纳与当前 `run_id` 匹配的状态响应，旧运行的迟到响应会被丢弃。

## 限制

- 不支持交互式输入（`input()` 会得到 EOF 异常）与第三方包（仅标准库）。
- 标准输出保留最近约 100K 字符，超出部分截断。

## 接口

| 方法 | 路径 | 请求体 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/run` | `{code}` | 启动运行，返回 `{run_id}`；已有活动运行返回 409 |
| POST | `/api/step` | `{run_id, pause_seq}` | 单步；重复/过期返回 409 |
| POST | `/api/continue` | `{run_id, pause_seq}` | 继续至结束；重复/过期返回 409 |
| POST | `/api/terminate` | `{run_id}` | 终止并回收子进程 |
| GET | `/api/state` | — | 当前运行完整状态（含 `run_id`、行号、局部变量、输出、异常） |
